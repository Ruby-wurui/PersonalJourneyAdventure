# 抓钩特效说明

## 新增特效组件：ClawEffects

为抓钩添加了多种电子脉冲和粒子流光特效，增强游戏的赛博朋克视觉效果。

### 特效类型

#### 1. 电子脉冲环 (Electric Pulse)
- **触发时机**：游戏进行中，抓钩悬停或持有胶囊时
- **效果**：两个脉动的霓虹环绕抓钩旋转
- **颜色**：青色和粉色交替
- **强度**：移动时更强，静止时较弱

#### 2. 粒子轨迹 (Particle Trail)
- **触发时机**：抓钩下降或上升时
- **效果**：30个粒子从抓钩位置发射，形成流光轨迹
- **颜色**：青色
- **特点**：使用加法混合模式，产生发光效果

#### 3. 能量场 (Energy Field)
- **触发时机**：抓钩抓住胶囊时
- **效果**：八面体线框围绕抓钩旋转
- **颜色**：粉色
- **特点**：脉冲式发光，强度随时间变化

#### 4. 闪电束 (Lightning Bolt)
- **触发时机**：抓钩下降或持有胶囊移动时
- **效果**：三条闪电从抓钩指爪连接到中心
- **颜色**：青色
- **特点**：锯齿状路径，每0.1秒更新一次形状

### 集成方式

特效组件已集成到 `ClawController` 中，会根据游戏状态自动显示/隐藏：

```tsx
<ClawEffects clawPosition={[x, y, z]} />
```

### 性能优化

- 使用 `useFrame` 进行高效动画更新
- 粒子系统使用 BufferGeometry 减少内存占用
- 特效根据状态条件渲染，避免不必要的计算
- 闪电效果使用节流更新（0.1秒间隔）

### 视觉效果

所有特效都使用了游戏的霓虹配色方案：
- 青色 (Cyan): `0x00ffff`
- 粉色 (Pink): `0xff00ff`

特效强度和可见性会根据抓钩状态动态调整，提供流畅的视觉反馈。
