# Product Overview

## Interactive Portfolio Website

An immersive full-stack portfolio experience that transforms traditional resume-style designs into a "tech adventure journey" with interactive 3D elements, real-time features, and engaging storytelling.

## Core Features

- **Interactive 3D Homepage**: Globe with skill points and particle systems using React Three Fiber
- **Adventure Map**: Project showcase as interactive islands with real-time demos
- **Tech Blog & Timeline**: Interactive timeline with code sandboxes, markdown support, and challenges
- **Personal Universe**: Galaxy-themed about page with 3D skill planets
- **AI Assistant**: Integrated chatbot for visitor interaction
- **Neon Claw Game**: Web-based 3D claw machine game with hand gesture controls
- **HanziShifter Game**: Unity WebGL Chinese character learning game
- **Internationalization**: Full i18n support for English and Chinese

## Design Philosophy

The portfolio is designed around "interaction + storytelling" to create an engaging experience that showcases technical skills through immersive, interactive elements rather than traditional static presentations.

## Visual Style

- **Cyberpunk/Neon aesthetic**: Dark backgrounds with neon highlights (pink, cyan)
- **Morandi color palette**: Soft, natural colors for comfortable viewing
- **3D elements**: Extensive use of Three.js for immersive experiences
- **Smooth animations**: Framer Motion for fluid transitions

## Target Audience

- Potential employers and clients
- Tech enthusiasts and developers
- Casual gamers (for the game features)
- Anyone interested in innovative web experiences
